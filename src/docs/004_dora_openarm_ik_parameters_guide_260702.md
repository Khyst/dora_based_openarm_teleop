# Dora OpenArm IK Node Parameter Tuning Guide

- **작업 일자**: 2026-07-30
- **작업 분류**: Docs

## 1. 개요 및 목적
본 문서는 `dora-openarm-kinematics` (`ik.py`) 노드가 로봇 가슴 기준점(`arm_origin`)의 말단 8D 포즈(`target_right`, `target_left`)를 수신하여, Mink (QP 기반 미분 IK 솔버) 알고리즘을 수행하고 16개 로봇 관절 각도(`position_right`, `position_left`)를 풀어내는 과정에서 사용되는 핵심 파라미터들의 역할과 사용자 튜닝 가이드를 정리하는 것을 목적으로 합니다.

---

## 2. IK 노드의 주요 역할 및 입출력 구조

```
[Quest Receiver] ➔ (target_right/left: 8D Pose) ➔ [dora-openarm-ik] ➔ (position_right/left: 8D Joint Angles) ➔ [OpenARM Driver / MuJoCo]
```

* **입력 데이터**: `target_right`, `target_left`
  * 포즈 구조: `[x, y, z, qw, qx, qy, qz, gripper_angle]` (로봇 가슴 `arm_origin` site 기준)
* **출력 데이터**: `position_right`, `position_left`
  * 관절 구조: `[q0, q1, q2, q3, q4, q5, q6, gripper_q]` (각 팔 당 8개 관절 각도, 라디안)

---

## 3. IK 파라미터 및 사용자 튜닝 가이드

IK 노드는 실행 시 다양한 옵션 파라미터를 넘겨받아 수행 방식 및 안정성을 조절합니다.

### 3.1 핵심 파라미터 요약 표

| 파라미터　　　　　　 | 기본값　　 | 주요 역할　　　　　　　　| 튜닝 시 가이드 및 효과　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　|
| :---------------------| :-----------| :-------------------------| :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`--mode`**　　　　 | `bimanual` | 조종 모드 선택　　　　　 | `bimanual` (양팔 동시), `right` (오른팔 전용), `left` (왼팔 전용) 중 선택.　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　|
| **`--dt`**　　　　　 | `0.02`　　 | 미분 적분 시간 간격　　　| Dataflow의 `tick` 주파수(예: 50Hz ➔ 0.02s)와 **반드시 일치**해야 관절 속도가 정상 계산됨.　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　 |
| **`--max-iters`**　　| `10`　　　 | 스텝 당 최대 연산 횟수　 | • **높이면 (`20 ~ 30`)**: 손끝 추종 목표 위치 정확도가 극대화됨.<br>• **낮추면 (`5 ~ 10`)**: 연산 시간이 짧아져 실시간성 확보 및 CPU 부담 감소.　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　 |
| **`--lm-damping`**　 | `0.1`　　　| Levenberg-Marquardt 감쇄 | 🌟 **특이점 방어 핵심 파라미터**<br>• 팔이 쫙 펴지는 한계선 근처에서 솔버가 튀는 것을 막아줌.<br>• **높이면 (`0.2 ~ 0.5`)**: 팔이 일자로 펴질 때 튀지 않고 부드럽게 멈춤.<br>• **낮추면 (`0.01`)**: 목표 위치에 더 정확히 도달하나 특이점에서 튈 위험 증가. |
| **`--damping`**　　　| `1.0`　　　| 관절 속도 감쇄력　　　　 | • **높이면 (`2.0 ~ 5.0`)**: 미세한 관절 떨림이 사라지고 부드러워짐 (반응은 약간 둔해짐).<br>• **낮추면 (`0.1 ~ 0.5`)**: 손을 민첩하게 추종함 (관절이 덜덜거릴 수 있음).　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　 |
| **`--posture-cost`** | `0.01`　　 | 중립 자세 유지 가중치　　| • **높이면 (`0.05 ~ 0.1`)**: 로봇 팔꿈치가 어색하게 꺾이지 않고 사람다운 기본 자세(Home)를 강하게 유지하려 함.<br>• **낮추면 (`0.001`)**: 목표 손위치를 맞추기 위해 팔꿈치 각도를 자유롭게 사용함.　　　　　　　　　　　　　　　　　　　　　　　　　　　　　|

## 4. 트러블슈팅 및 현상별 튜닝 시나리오

### 🚨 시나리오 1: 사람이 팔을 쫙 뻗었을 때 로봇 팔이 거칠게 꺾이거나 튈 때
* **원인**: 로봇 한계 영역(Singularity)에 도달하여 IK 솔버의 관절속도 계산이 순간적으로 발산하는 현상.
* **조치 방법**:
  * `--lm-damping` 값을 기존 `0.1`에서 **`0.2 ~ 0.3`으로 올려 감쇄력을 강화**합니다.
  * 필요시 `--posture-cost`를 올려 팔꿈치 꺾임 현상을 억제합니다.

### 🐢 시나리오 2: 손 움직임 대비 로봇 추종 반응이 너무 느리고 둔할 때
* **원인**: IK 솔버의 가중 감쇄력(--damping)이 너무 크거나, 최대 연산 횟수가 적어 목표에 도달하지 못함.
* **조치 방법**:
  * `--max-iters`를 `10`에서 **`20`으로 증가**시킵니다.
  * `--damping`을 `1.0`에서 **`0.5`로 낮춥니다.**

### 📳 시나리오 3: 손을 고정하고 있는데 로봇 관절이 미세하게 덜덜거릴 때
* **원인**: 수신되는 목표 포즈의 잔여 노이즈 또는 IK 관절 속도가 과도하게 정밀하게 쫓아가려는 현상.
* **조치 방법**:
  * `--damping`을 `1.0`에서 **`2.0`으로 증가**시킵니다.
  * (Quest Receiver 단의 `min_cutoff` 필터를 약간 낮추어 포즈 데이터 노이즈를 1차 차단합니다.)

## 5. 실제 Dataflow 설정 파일 (`dataflow-nana-teleop.yaml`) 적용 예시

```yaml
  - id: ik
    build: pip install -e ../../dora-openarm-kinematics
    path: dora-openarm-ik
    args: "--xml ../../../nana_v3_description/assets/robot/urdf/nana_v3.xml --mode bimanual --max-iters 10 --dt 0.02 --damping 1.0 --posture-cost 0.01 --lm-damping 0.1"
```

## 6. 테스트 및 승인 내용
- **검증 방식**: `ik.py` 소스 코드 및 `openarm_control` IK solver 파라미터 매핑 분석 완료.
- **결과**: `dora-openarm-kinematics` 노드의 유의미한 6대 파라미터에 대한 역할 분석 및 현상별 트러블슈팅 튜닝 가이드 작성 완료.
