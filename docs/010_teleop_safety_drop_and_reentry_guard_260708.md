# VR 텔레옵 안전 가드 로직 원복 (반응성 저하로 인한 철회)

- **작업 일자**: 2026-07-31
- **작업 분류**: Revert / Responsiveness Restoration

## 1. 개요 및 목적
- IK 타겟 점프 차단 로직 적용 시 텔레옵 실시간 제어 반응성이 현저히 저하되는 문제가 발생하여, 해당 차단 로직을 완전히 **철회하고 1:1 실시간 직결 반응성 모드로 원복**함.

## 2. 복구 내용
- `ik.py` 내의 `JUMP_THRESHOLD_METERS` 3D 점프 차단 코드 제거 완료.
- 실시간 50Hz 1:1 최고 반응성 직결 IK 모드로 원복.
