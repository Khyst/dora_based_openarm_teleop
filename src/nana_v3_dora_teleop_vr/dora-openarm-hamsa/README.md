# dora-openarm-hamsa

Dora node to control Hamsa hands (Right & Left) using VR controller button events received from `udp-receiver`.

## Mappings
- **button_a**: Toggle Right Hand (Right Grip <-> Right Release)
- **button_x**: Toggle Left Hand (Left Grip <-> Left Release)
- **button_b**: Toggle Right Hand (Right Scissor <-> Right Release)
- **button_y**: Toggle Left Hand (Left Scissor <-> Left Release)
