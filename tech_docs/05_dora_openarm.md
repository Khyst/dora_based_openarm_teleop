## 1. 개요 및 모듈 목적
---
본 문서는 `nana_openarm_teleop` 시스템에서 IK 솔버 노드가 계산한 7-DOF 관절 각도 목표값(`position_right`/`left`)을 수신하여, CAN-FD 버스 기반 실제 OpenArm 물리 로봇 팔 모터 드라이버(`openarm_driver`)에 실시간 제어 명령을 전송하고 관절 피드백 데이터를 수집하는 `dora-openarm` (`follower-right` / `follower-left`) 노드의 기술 명세를 정리합니다.

- **실행 노드명**: `follower-right` (오른팔 제어), `follower-left` (왼팔 제어)
- **드라이버 백엔드**: `openarm_driver` (CAN-FD 버스 통신 인터페이스)

## 2. 제어 상태 기계 및 안전 Alignment 메커니즘
---
### 2.1 ArmStatus 제어 상태 기계 (State Machine)
---
로봇 팔의 안전 구동을 보장하기 위해 3단계 제어 상태 기계를 운용합니다.

| 상태 명칭 (Status) | 주요 동작 내용                                                                       | 상태 전환 조건 (Transition)    |
| :------------: | :----------------------------------------------------------------------------- | :----------------------- |
| **`STOPPED`**  | 모터 제어 명령 전송 중단 및 대기 상태                                                         | 노드 초기화 직후                |
| **`STARTED`**  | CAN-FD 통신이 연결되고 IK 목표 수신을 개시한 상태                                               | `openarm_driver` 수신 성공 시 |
| **`ALIGNED`**  | **안전 얼라인먼트 완료 상태**. IK 목표 각도와 실제 관절 각도의 오차가 임계값 이하로 좁혀져 1:1 직결 실시간 제어가 수행되는 상태 | `_align` 단계 수렴 완료 시      |

### 2.2 안전 얼라인먼트 보간 로직 (`_align`)
---
텔레옵 개시 시 오퍼레이터의 VR 포즈(IK 목표)와 실제 로봇 팔의 현재 관절 위치 사이에 큰 격차가 존재할 수 있습니다. 이 격차로 인해 모터가 급격히 튀어 로봇이나 주변 집기가 파손되는 것을 방지하기 위해 수치 보간 제어를 수행합니다.

- **관절 오차 계산**: $\Delta \mathbf{q} = \mathbf{q}_{\text{target}} - \mathbf{q}_{\text{current}}$
- **안전 스텝 제한 보간**: 
  $$\mathbf{q}_{\text{next}} = \mathbf{q}_{\text{current}} + \text{clip}(\Delta \mathbf{q}, -\text{step\_limit}, +\text{step\_limit})$$
  - **`step_limit` 기본값**: `0.001 rad/step` ($250\text{Hz}$ 루프 기준 스텝당 최대 $0.057^\circ$ 이하로 부드럽게 접근)
- **수렴 판정**: 모든 관절의 위치 오차가 설정된 임계치 이하로 감소하면 `ALIGNED` 상태로 즉시 전환되어 직결 텔레옵 구동 개시.

## 3. 데이터 처리 파이프라인 (Data Processing Pipeline)
---
### 3.1 목표 관절 각도 수신 및 디코딩
---
`position_right` / `position_left` 노드 신호로부터 PyArrow StructArray `[{"qpos": float32[8]}]`를 파싱하여 목표 관절 각도 추출.

### 3.2 제어 상태 검증 및 보간 처리
---
- 현재 제어 상태가 `STARTED`인 경우 `_align()` 보간 함수를 거쳐 부드러운 intermediate 목표각 계산.
- `ALIGNED` 상태인 경우 목표 관절 각도를 즉시 모터 명령으로 인가.

### 3.3 CAN-FD 버스 통신
---
`openarm_driver.RobotArm.set_joint_target()`을 호출하여 CAN-FD 버스를 통해 7축 Revolute 관절 모터에 실시간 제어 패킷 전송.

### 3.4 모터 피드백 수집 및 Dora 출력
---
- `fetch_position()`을 호출하여 모터 인코더의 실제 각도를 읽어옴.
- `arm_right_observation` / `arm_left_observation` 패킷으로 하류 기록 노드 전달 및 IK 동기화용 `position` 출력 전송.

---

| :------------------- | :----------------------- | :---------------------------------------------------------------- | :------------------------------------ |
| **`tick`**           | `dora/timer/millis/2`    | `{"timestamp": 1723456789}`                                       | 250Hz 데이터플로우 메인 틱 신호                  |
| **`position_right`** | `[{"qpos": float32[8]}]` | `[{"qpos": [0.12, -0.34, 0.05, 0.82, -0.11, 0.04, 0.02, 1.0]}]`   | `ik` 노드가 계산한 오른팔 목표 관절 각도 (오른팔 노드 수신) |
| **`position_left`**  | `[{"qpos": float32[8]}]` | `[{"qpos": [-0.12, -0.34, -0.05, 0.82, 0.11, 0.04, -0.02, 1.0]}]` | `ik` 노드가 계산한 왼팔 목표 관절 각도 (왼팔 노드 수신)   |
### 4.2 Outputs
---

| Output ID                   | 데이터 형식 (Type)            | 데이터 예시 (Example)                                                  | 간단 설명 (Description)                    |

| **`arm_right_observation`** | `[{"qpos": float32[8]}]` | `[{"qpos": [0.12, -0.34, 0.05, 0.82, -0.11, 0.04, 0.02, 1.0]}]`   | 오른팔 실제 관절 피드백 관측값 (오른팔 노드 전송)          |
| **`arm_left_observation`**  | `[{"qpos": float32[8]}]` | `[{"qpos": [-0.12, -0.34, -0.05, 0.82, 0.11, 0.04, -0.02, 1.0]}]` | 왼팔 실제 관절 피드백 관측값 (왼팔 노드 전송)            |
| **`status`**                | `string`                 | `"ready"`                                                         | OpenArm CAN-FD 하드웨어 제어 노드 정상 준비 완료 신호  |
