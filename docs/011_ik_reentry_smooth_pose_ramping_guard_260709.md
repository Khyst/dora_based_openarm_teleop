# IK 포즈 램핑 보간 로직 원복 (반응성 저하로 인한 철회)

- **작업 일자**: 2026-07-31
- **작업 분류**: Revert / Responsiveness Restoration

## 1. 개요 및 목적
- IK 재진입 시 포즈 보간(`_ramp_pose`) 적용으로 인해 텔레옵 손 추종 지연(Lag) 및 반응성 저하 현상이 발생함에 따라, 해당 **램핑 보간 로직을 삭제하고 원본 1:1 직결 반응 모드로 복구**함.

## 2. 복구 내용
- `ik.py` 내의 `_ramp_pose` 보간 함수 및 `MAX_STEP_METERS_PER_TICK` 속도 제한 제거.
- 이전 원본의 50Hz 딜레이 없는 1:1 직결 반응 모드 복구.
