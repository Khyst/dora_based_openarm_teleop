# NANA v3 하드웨어 시작/종료 포즈 A-Pose 설정

- **작업 일자**: 2026-07-31
- **작업 분류**: Configuration / Kinematics

## 1. 개요 및 목적
- 하드웨어 텔레옵 시 구동 시작(`arm.start()`) 및 종료(`arm.stop()`) 시 차단적 차렷 자세(`[0, 0, 0, 0, 0, 0, 0, 0]`) 대신 **A-Pose (어깨 $\pm 30^\circ$, 팔꿈치 $+30^\circ$ 준비 자세)**로 2초간 부드럽게 기립하도록 드라이버 설정을 업데이트함.

## 2. 주요 변경 사항

- **수정 파일**: `src/nana_v3_dora_teleop_vr/openarm_driver/src/openarm_driver/configs/nana_v3_cell.yaml`
- **적용된 A-Pose 관절 설정 수치**:
  - `right_arm`: `[0.5236, 0.0, 0.0, 0.5236, 0.0, 0.0, 0.0, 0.0]` (어깨 $+30^\circ$, 팔꿈치 $+30^\circ$)
  - `left_arm`: `[-0.5236, 0.0, 0.0, 0.5236, 0.0, 0.0, 0.0, 0.0]` (어깨 $-30^\circ$, 팔꿈치 $+30^\circ$)

## 3. 효과
- 로봇을 시작할 때 IK 특이점(Singularity) 구역인 차렷 자세를 피하고, 팔을 살짝 벌리고 굽힌 준비 자세(A-Pose)로 시작하여 VR 텔레옵 초기 정합 시 최상급 가동성과 안전성을 확보함.
